本堂課教材包含互動學習單、簡報、所需圖片與學生拼裝版 `.sb3`。更新時請保留此資料夾結構與相對連結，覆蓋相同課程資料夾中的新版檔案，再提交並推送至 `main`；網址就會沿用。Git 提交紀錄可回查每次改版。

## 新增後續課程

在 `lessons/` 下新增固定名稱的課程資料夾，例如 `05-lesson-name/`，並提供該課的 `index.html`、`presentation/`、`assets/` 和需要的 `downloads/`。再更新根目錄 `index.html` 加上學習單和簡報入口。

## 公開內容範圍

本儲存庫與 GitHub Pages 網站為公開內容。只放已確認適合公開的學生教材、簡報、圖片和練習檔；教師完成版 Scratch 專案及私人原始素材留在原專案資料夾。
