# 第四堂 Scratch 互動學習單｜使用說明

## 課程與檔案

- 課程名稱：星光多邊形城堡：畫出你的魔法印記！
- 對象：國小四年級 Scratch 學生。
- 學習單：`index.html`
- 講師簡報：`presentation/index.html`
- 學生拼裝版：`downloads/學生練習版_多邊形城堡積木拼裝.sb3`
- 教師完成版：專案根目錄的 `Scratch 專案多邊形城堡闖關遊戲4版多角色.sb3`

請保留 `assets/`、`downloads/` 和 `presentation/` 資料夾。學習單及簡報可離線使用；瀏覽器遊戲區是依玩法重製的示意，不是 Scratch `.sb3` 執行器。

## 開啟與操作

1. 在 Windows 檔案總管雙擊 `index.html`，以 Edge 或 Chrome 開啟。
2. 學習單上方按「開始／重新開始」，按 `1`、`2`、`3`、`4` 選擇形狀；答對後用方向鍵走到城門。也可使用頁面上的按鈕操作。
3. 下載學生拼裝版，在 Scratch Desktop 選「檔案 → 從電腦載入」。學生版只拆開畫筆角色的正方形、正六角形、正八角形及多個正六角形所需的迴圈／移動／轉向積木；其他遊戲程式保留。
4. 學習單可用「列印／另存 PDF」列印。任務勾選、文字回答與畫面註記只保存在目前瀏覽器；共用電腦下課後請清除記錄。
5. 簡報可用側邊導覽或方向鍵翻頁；按 `N` 或「講師提示 N」顯示本頁講師提示，按「全螢幕」投影。

## 課堂主線

先玩成果 → 看角色、變數和訊息 → 拼正方形 → 比較六角形與八角形 → 認識畫筆功能 → 把圖案接回闖關 → 暗室巢狀重複加碼。正式課程節奏為 120 分鐘，詳見學習單與簡報。

孩子使用 `x`、`y` 座標移動小巫師；按數字鍵設定 `玩家選擇`；畫筆收到 `畫形狀` 後依玩家選擇作畫；程式比對 `玩家選擇` 與 `目標形狀` 後打開城門。正多邊形的範例使用「重複次數 = 邊數」及「轉角 = 360 ÷ 邊數」。

## 來源與已知狀況

- 內容依據專案根目錄教師完成版 `.sb3` 的角色、造型、背景、變數、廣播和積木；學生版由該檔另存後，只拆分畫筆多邊形積木。
- 學習單及簡報沿用第三堂互動教材的教學節奏、教學工具列與講師／主協辦資訊，並使用本課獨立的瀏覽器記錄鍵。
- 第四版建立了 `遊戲結束` 變數，但目前程式沒有初始化或讀取它；通關後方向鍵仍可能移動。舞台在第 4 關設定中會重複廣播 `重置本關`，小巫師接收重置時也會先切換一個背景再依關卡選背景。這些是教師版程式目前的狀態，教材已放入教師備課提示，不把變數或多重重置列作學生必做功能。
- 變數判斷比對的是玩家選擇的文字和目標文字，不會辨認舞台上實際畫出的圖形；教師請以筆跡檢查學生是否完成組裝。
- 未發布網站；教師完成版 `.sb3` 沒有複製到學生下載資料夾。
